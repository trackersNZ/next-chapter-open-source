# Contributing

Thanks for helping improve Next Chapter.

## Development workflow

1. Fork the repository and create a focused branch.
2. Run the app locally with `npm run dev`.
3. Add or update tests for behavior changes.
4. Run `npm run check` before opening a pull request.
5. Explain the user impact and privacy implications in the pull request.

Backend changes also require `npm install` and `npm run check` from `backend/`.

## Project principles

- Keep the frontend useful without an account or hosted backend.
- Do not add bundled treatment plans, personal records, credentials, or live deployment identifiers.
- Treat health, reminder, and reflection data as sensitive.
- Preserve keyboard access, readable focus states, and reduced-motion support.
- Prefer small dependencies and progressive enhancement.

By participating, you agree to keep discussion constructive and respectful.
